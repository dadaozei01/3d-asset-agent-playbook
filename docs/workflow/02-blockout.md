# 02 大形与比例

## 目标

用最简单的几何体搭出正确的轮廓、比例和部件关系，尽快让用户确认方向。

## 做法要点

- 使用真实单位（米），按目标平台的朝向约定建模；原点放在使用时最方便的位置（门、墙放底部中心）。
- 部件分开建：每个部件一个物体，命名有规律（`Door_Frame_L`、`Door_Plank_3`）。后续材质、UV 和遮罩计算都依赖这种清晰的结构。
- 重复部件（铆钉、螺栓、木板）用同一份网格的实例或脚本批量生成，排布按参考的规律（等距、成对、避开角落）。
- 放一个简单相机和灯光，第一版就用接近最终的角度看图。

## 做对了的标准

- 轮廓和比例与参考一致，部件齐全（对照 01 的清单逐项检查）。
- 正面、侧面、背面都看过。
- 用户确认了方向，或者没有提出反对。
