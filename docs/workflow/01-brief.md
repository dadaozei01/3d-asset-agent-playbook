# 01 需求与参考

## 目标

在动手建模前，弄清楚“做什么、给谁用、长什么样”。

## 要弄清的事

- **用途与平台**：游戏引擎（UE / Unity）、实时 Web、离线渲染、3D 打印？决定面数、贴图规格和导出格式。
- **观看距离**：远景道具、可走近的场景物件、特写主角？决定细节量和贴图密度。
- **哪些面会被看到**：只看正面，还是正反两面、四周都可见？门、箱子、围栏这类东西默认两面都要做。
- **风格**：从参考图判断风格，或在 [styles/](../../styles/) 里找对应档案；没有就按模板新建。

## 拆解参考图

把参考拆成可执行的清单：

1. **形体部件**：主体、框架、加固件、连接件、装饰。注意容易漏的部件，例如角落的护角铁片、铆钉的排布规律。
2. **材质分区**：每种材质是什么、占多大面积、相互怎么交接。
3. **使用痕迹**：磨损在哪里（边角、凸起、接触点）、脏污在哪里（凹处、缝隙、连接件周围）、程度多重。
4. **比例**：用参考中的已知物体（人物、地砖）估算尺寸。

## 做对了的标准

- 能用一两句话复述需求，并列出部件和材质清单。
- 知道最终交付格式与平台。
- 不确定的关键点（例如是否需要背面、目标平台）已经问过，或已按合理默认值做并在回复中说明。
