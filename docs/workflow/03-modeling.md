# 03 建模与细节

## 目标

在大形基础上补足细节，让模型在目标观看距离下“读得清”。

## 做法要点

- **倒角**：几乎所有硬边都需要小倒角，否则看起来像玩具或 CG 方块。先用非破坏的倒角修改器，交付前再应用。风格化模型的倒角可以偏大，写实模型按真实工艺。
- **几何还是贴图**：会产生轮廓变化的细节（护角、铆钉、凸起的木板）用几何；只影响表面的细节（木纹、划痕）用贴图或法线。
- **缝隙**：木板、拼接处留真实的缝，并在缝后面放深色背板或封底，避免透光。
- **面数预算**：按 01 定的平台控制面数。重复小物件（铆钉）控制段数，例如 16×8 的球体已经足够。
- **法线与平滑**：平滑着色配合倒角；检查有没有翻转的法线和重叠的面。

## 做对了的标准

- 近景看边缘有倒角、有高光过渡。
- 没有漏缝透光、没有穿插。
- 面数在预算内，并记录下来以便交付时报告。
