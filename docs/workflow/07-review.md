# 07 验收

## 目标

在交给用户前，用用户的眼光检查一遍，主动发现问题。

## 检查清单

- [ ] 与参考对比：部件齐全、比例一致、风格一致。
- [ ] 多角度：正面、45°、侧面、背面、顶部；近景特写边角和连接件。
- [ ] 背光面：依赖光照的效果是否还在。
- [ ] 贴图：无接缝、无拉伸、无多余元素、清晰度够。
- [ ] 交付版（烘焙贴图）与制作版并排比较。
- [ ] 文件：相对路径、无临时路径、无多余文件。
- [ ] 目标平台导入（能做时实测；做不了时明确说明未实测）。

## 汇报格式

1. 结果：做成了什么，放在哪里。
2. 验证：看过哪些角度、对比过什么。
3. 改动：动过用户哪些东西（相机、灯光、隐藏的物体）。
4. 未完成或未验证的部分。
5. 可选的下一步，最多一两条。
