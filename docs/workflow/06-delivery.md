# 06 交付与导出

## 目标

交出一个用户拿到就能用、结构清楚、移动后不丢贴图的资产包。

## 默认文件夹结构

用户没有另外指定时：

```
~/Desktop/3D 模型/<资产名>/
├── <资产名>.<软件格式>      源文件（.blend / .ma / .max …）
├── SM_<AssetName>.fbx       导出模型
└── 材质/                     所有贴图
    ├── T_<AssetName>_<Part>_BaseColor.png
    ├── T_<AssetName>_<Part>_Normal.png
    ├── T_<AssetName>_<Part>_ORM.png
    └── T_Tile_*.png         制作用的平铺源贴图（备份）
```

## 要点

- **另存为**到新文件夹，不覆盖用户原来的文件。
- 贴图路径改为相对路径，确认软件里没有指向临时目录的贴图。
- 清理：删除中间图、未使用的数据、软件自动备份（如 `.blend1`），除非用户要保留。
- 合并：交付网格合并为一个物体，材质槽按材质类型划分，尽量少（例如木头 / 金属 / 铆钉）。只在需要时多拆。
- 原点与变换：应用变换，原点放在使用位置（底部中心），朝向与单位符合目标平台。
- 源文件里保留隐藏的可编辑版本，以便日后修改后重新烘焙。

## 做对了的标准

- 关闭软件后重新打开源文件，贴图都在。
- 文件夹里只有用户需要的文件。
- 交付说明列出：文件清单、面数、材质槽、贴图分辨率、未验证的部分。
