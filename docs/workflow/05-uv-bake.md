# 05 UV 与烘焙

## 目标

把软件里的材质效果变成引擎能读的网格 + UV + 贴图，并尽量不损失质量。

## 为什么要烘焙

FBX / glTF 只带网格、UV、材质槽名。软件里的节点效果（边缘遮罩、AO 节点、按物体坐标算的高光、透明贴花）到了引擎里全部丢失。要所见即所得，就要把它们烘进贴图，或在引擎里重做。

## 两种 UV 的分工

- **平铺 UV**：按真实尺寸展开，配合无缝贴图，清晰度高、贴图小。适合制作阶段和“底色贴图 + 遮罩”的混合方案。
- **唯一 UV**：每个面在贴图上独占一块，用于烘焙。清晰度受贴图分辨率限制。

可以在同一模型上保留两套 UV：制作时用平铺 UV 采样，烘焙时以唯一 UV 为目标。注意贴图节点要明确指定采样哪一套 UV，否则新增 UV 层会改变外观。

## 清晰度计算

像素/厘米 ≈ 贴图边长 × √(UV 填充率 ÷ 表面积 m²) ÷ 100。

- 先算再定分辨率，并和原来的平铺清晰度比较。
- 看不见的面（夹在中间的背板、被盖住的面）只给很小的 UV 空间，把面积让给可见面。

## 烘焙策略

- 在副本上烘焙：复制部件、应用修改器，原始程序化版本保留。
- 先应用倒角再展 UV，避免修改器插值拉伸 UV。
- 标准 PBR 一组：BaseColor（含 AO、磨损、脏污）、Normal（切线空间）、ORM（R=AO，G=Roughness，B=Metallic）。
- 引擎读不到的通道（金属度、自定义遮罩）可以临时接到 Emission 再烘。
- 叠在表面上的透明贴花普通烘焙拍不到：可以烘一张 Position（世界坐标）图，再按到贴花中心的距离在图上重建效果。
- 重复的小物件（铆钉）共享一份 UV 和贴图，只烘一个。
- 烘焙出 Normal 等数据图时用 Non-Color；BaseColor 用 sRGB。

## 做对了的标准

- 只用烘焙贴图的材质，看起来与原材质基本一致（并排比较）。
- 贴图边缘有足够的出血（margin），没有接缝黑边。
- 报告了每组贴图的分辨率和实际清晰度。
